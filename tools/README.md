# Актуализация страницы «Склад под пиво»

Страница: https://maxstep198622-svg.github.io/open-sites/sklad-pivo/ (файл `sklad-pivo/index.html`, все данные и фото зашиты внутрь).

Раз в неделю (понедельник) страница обновляется так:

1. Проверить объявления из финала и запаса: висит ли, цена, дата обновления.
2. Найти новые объявления под условия страницы.
3. Записать результат в `sklad-pivo/updates/ГГГГ-ММ-ДД.json`.
4. Выполнить из корня репозитория: `python tools/update_sklad.py sklad-pivo/updates/ГГГГ-ММ-ДД.json`
5. Проверить вывод скрипта (список финала и запаса, кто сменил вердикт), затем `git add -A && git commit && git push`. Через 1–2 минуты страница обновится.

Скрипт сам пересчитывает вердикты, свежесть (3 месяца от даты проверки), места, счётчики, таблицу отсева и журнал обновлений. Руками `index.html` не править.

## Условия страницы (заданы владельцем 29.10.2026, не менять)

Финал: только аренда; склад, не производство; Кировский или Ленинский район Новосибирска; класс A/B; потолок от 9,5 м; в тексте объявления есть ж/д рампа или пандус у ветки (тупик без рампы не подходит); от 8 000 паллетомест; объявление обновлялось не раньше чем 3 месяца назад. Запас: всё то же, но 6 000–8 000 паллетомест или их не посчитать. Комплекс на ул. Петухова 69–79 стоит первым и не отсеивается по возрасту объявления.

## Как проверять

Основной способ для карточек финала и запаса — открыть само объявление в браузере владельца через расширение Claude in Chrome (разрешено владельцем 16.11.2026): одна новая вкладка, только чтение, без входа в аккаунты, без нажатий, заявок и показа телефонов. Если площадка показала капчу или требует входа — не решать и не обходить, остальные карточки этой площадки пропустить и назвать площадку в итоге.

Без браузера Домклик (401), Циан, Авито и Яндекс Недвижимость для автоматического чтения закрыты. Запасные источники:

- зеркало `arendacre.mirkvartir.ru` — копии объявлений Яндекса и Авито с датами «размещено» и «обновлено» и признаком архива;
- `novosibirsk.move.ru`, `novosibirsk.skladoiskatel.ru`, `skladium.ru`, сайты брокеров;
- поисковые сниппеты (помечать «по сниппету»).

Чего не видели на странице или в сниппете — не писать. Если объявление проверить не удалось, в `checks` его не включать: скрипт сам пометит «не проверено».

## Формат файла обновления

```json
{
  "date": "2026-11-16",
  "summary": "Одна-две фразы для журнала: что проверено, что изменилось, что нового.",
  "checks": [
    {
      "keys": ["Д2077369075"],
      "status": "активно",
      "how": "Как и где проверено, с датами.",
      "upd": "2026-09-22",
      "rub": 14500000
    }
  ],
  "new": [
    {
      "key": "Н20261116-1",
      "src": "Авито",
      "url": "https://...",
      "place": "Новосибирск, улица ..., дом",
      "rayon": "Ленинский",
      "kind": "склад",
      "area": 5000, "sklad_area": 4200,
      "rub": 4000000, "vat": "без НДС",
      "h": 12.0, "klass": "A", "teplo": "да", "doki": 6,
      "zhd": "A", "zhd_cit": "дословная цитата про ж/д из объявления",
      "date": "2026-11-10", "seller": "Агентство",
      "pm_stated": null,
      "text": "Текст объявления.",
      "lat": 54.99, "lon": 82.85,
      "note": "Что нужно уточнить."
    }
  ]
}
```

- `checks[].keys` — ключи карточек (`key` в данных страницы; виден как `id` карточки). `status`: `активно`, `снято` (карточка уйдёт в отсев) или `не проверено`. `upd` — дата последнего обновления объявления, если видна. `rub` — цена в месяц, только если она отличается.
- `new[].zhd`: `A` — рампа или пандус у ветки, `B` — ветка или тупик без рампы, `N` — ж/д в тексте нет. `kind`: `склад` или `производство`. `rayon`: район города; для объекта за городом добавить `"city": false, "kmb": км`. `teplo`: `да`, `нет`, `частично` или пусто. `pm_stated` — паллетоместа, если названы в объявлении; иначе скрипт оценит сам. Неизвестные поля не заполнять.
- Ключ нового объявления: `Н` + дата + номер; при повторном запуске карточка с тем же ключом заменяется.
- Объявление, которое уже есть на странице (тот же адрес и площадь), в `new` не добавлять — только в `checks`.
